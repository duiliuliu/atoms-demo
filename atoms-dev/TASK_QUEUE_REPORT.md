## 实现概述

本次实现完成了以下两个主要功能：

### 1. 前端展示优化
- **消息类型扩展**：支持文本消息、任务分解卡片、任务执行卡片
- **统一时间线展示**：任务卡片与普通消息按时间顺序展示
- **实时进度更新**：任务执行状态实时显示

### 2. 任务拆解体系优化
- **任务队列管理器**：独立的 TaskQueueManager 模块
- **分批执行机制**：支持 1-2 个任务/批次执行
- **进度持久化**：任务状态自动保存到磁盘
- **上下文关联**：每批次执行后保持上下文连贯

## 架构设计

### 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      前端层                                  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │  ChatContainer│  │MessageBubble│  │TaskConfirm. │       │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
│                              ↓                               │
│  ┌────────────────────────────────────────────────────┐     │
│  │  Stores (Zustand)                                 │     │
│  │  - ChatStore (EnhancedMessage[])                  │     │
│  │  - TaskStore (TaskBreakdown)                      │     │
│  └────────────────────────────────────────────────────┘     │
└─────────────────────────────────────────────────────────────┘
                            ↓ Socket Events
┌─────────────────────────────────────────────────────────────┐
│                   WebSocket层                                │
│  新增事件：task:batch_start, task:progress, task:batch_comp │
└─────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────┐
│                  后端服务层                                  │
│  ┌────────────────────────────────────────────────────┐     │
│  │  TaskQueueManager（新）                            │     │
│  │  - createQueue() 创建队列                         │     │
│  │  - getCurrentBatch() 获取当前批次                 │     │
│  │  - updateTaskStatus() 更新状态                    │     │
│  │  - moveToNextBatch() 移动到下一批次               │     │
│  └────────────────────────────────────────────────────┘     │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐       │
│  │MemoryManager │  │AgentService  │  │SocketHandler│       │
│  └──────────────┘  └──────────────┘  └──────────────┘       │
└─────────────────────────────────────────────────────────────┘
```

### 数据流

```
用户输入 → IntentClassifier → TaskAnalyzer
                              ↓
                    TaskBreakdown (任务拆分)
                              ↓
              SocketHandler.task:confirm
                              ↓
              TaskQueueManager.createQueue()
                              ↓
              executeTasksBatch() (分批执行)
                              ↓
              AgentService.processRequest()
                              ↓
              task:batch_complete (循环直到完成)
                              ↓
              MemoryManager (保存记忆)
```
