## 详细设计

### 1. 产品概述

Atoms.dev 是一个 AI 驱动的全栈开发平台，用户通过自然语言对话即可完成网站、应用和游戏的开发与部署。平台核心理念是"把想法变成可销售的产品"，无需编程经验即可使用。

**核心价值主张**：
- 零代码门槛：通过自然语言描述需求即可生成完整应用
- AI Agent 团队协作：多个专业 AI 角色协同完成复杂任务
- 一站式开发：从设计到部署全流程覆盖
- 实时预览：开发过程中即时查看效果

---

### 2. 注册与登录

#### 2.1 注册方式
- **邮箱注册**：使用电子邮件地址创建账户
- **第三方登录**：支持 Google、GitHub 等社交账号快速登录

#### 2.2 账户管理
- 个人资料设置
- 订阅计划管理
- 积分余额查看
- 账单历史记录

---

### 3. 工作模式

#### 3.1 工程师模式 (Engineer Mode)
- **定义**：仅激活工程师 Agent @Alex
- **适用场景**：代码编写、Bug修复、简单功能实现
- **特点**：单Agent工作，效率高，响应更快，积分消耗更少

#### 3.2 团队模式 (Team Mode)
- **定义**：调用多个 Agent 协作
- **适用场景**：完整项目开发、需求分析、系统设计
- **特点**：多Agent协作，覆盖全流程

> 💡 切换方式：在输入框下方的按钮处切换模式

### 5. 核心功能操作

#### 5.1 创建项目

1. 在对话框中描述你的需求（如"创建一个电商网站"）
2. AI 团队自动分析需求并制定开发计划
3. 确认计划后，Agent 自动执行开发
4. 实时查看开发进度和代码生成

#### 5.2 代码编辑器 (Editor)

- 点击右侧边栏的 Editor 按钮查看所有生成的文件
- 支持直接选择文件并进行修改
- 语法高亮和代码格式化
- 文件树导航

#### 5.3 终端 (Terminal)

- 点击右侧边栏的 Terminal 按钮
- 查看 Agent 的执行命令和输出
- 了解项目构建和部署过程

#### 5.4 应用预览 (App Viewer)

- 实时预览应用构建结果
- **替换元素**：选中元素后在输入框描述替换内容
- **添加/更换图片**：选中元素后点击"add or exchange"
- **发布网站**：点击 Publish 按钮，可编辑URL后直接发布

#### 5.5 Bug 修复

- 当构建遇到问题时，左下角出现 Bug Report
- 可选择"Fix all"一键修复
- 或展开查看具体错误详情后逐一处理

#### 5.6 版本管理 (Remix)

- 点击对话区域内的 Remix 图标，从当前版本分支
- 保留开发上下文，通过版本摘要跟踪变更
- 优化资源使用，防止积分快速消耗
- 点击右上角"Versions"按钮切换版本

---

### 6. 文件与资源管理

#### 6.1 上传文件

- 点击输入框左下方的"+Add"按钮
- 支持上传单个文件或整个文件夹
- 支持的文件类型：文本、代码、图片、文档等

#### 6.2 上传图片

- 通过文件上传选择图片
- 或直接复制图片后粘贴到输入框

---

### 7. 分享与协作

#### 7.1 分享设置

- 点击右上角分享按钮
- **Public**：任何人可查看
- **Secret**：仅拥有链接的人可查看
- **Private**：仅自己可查看

#### 7.2 导出与社交分享

- Export 按钮：下载所有代码文件
- 社交平台分享：X、Instagram、LinkedIn、TikTok
- 复制分享链接

---

### 8. Atoms Cloud 后端服务

Atoms Cloud 是自建后端平台，让零开发经验的用户也能轻松配置网站后端。

| 服务 | 功能 |
|------|------|
| 用户认证 (Auth) | 用户注册、登录、会话管理 |
| 数据库 (Database) | 基于 PostgreSQL 的实体 CRUD 和表管理 |
| 文件存储 (File Storage) | 图片、视频等文件的对象存储 |
| 边缘函数 (Edge Functions) | 自定义服务端 API 端点 |
| AI 能力 | 文本/图片/视频/音频生成、PDF分析、语音转录 |
