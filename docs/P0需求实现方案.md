# P0 需求实现方案：智能体驱动的可视化应用生成平台

## 一、项目概述

### 1.1 产品愿景

打造一款**零门槛的智能应用生成平台**，用户通过自然语言描述需求，AI 智能体自动完成代码编写，并在右侧实时预览生成效果。核心体验是"说即所得"——所见即所得的开发模式。

### 1.2 核心能力矩阵

| 能力项 | 描述 | 优先级 |
|--------|------|--------|
| 自然语言交互 | 用户描述需求，AI 理解并执行 | P0 |
| 智能体协作 | 单 Agent 驱动，可扩展多 Agent | P0 |
| 实时预览 | 代码变更即时渲染 | P0 |
| 代码编辑器 | 查看/编辑生成代码 | P0 |
| 一键部署 | 生成应用可访问 URL | P1 |

### 1.3 MVP 范围

```
MVP 包含：
✅ 自然语言输入 → AI 解析需求
✅ 单 Agent 驱动 → 代码生成
✅ 实时预览 → iframe 渲染
✅ 代码编辑器 → 查看/简单编辑
✅ 基础终端 → 命令执行日志

MVP 不包含：
❌ 多 Agent 协作（后续迭代）
❌ 完整版本管理（后续迭代）
❌ Atoms Cloud 后端（后续迭代）
❌ 思维链展示（后续迭代）
```

### 4.1 前端 - 对话界面

```tsx
// ChatContainer.tsx
import React, { useRef, useEffect } from 'react';
import { useChatStore } from '@/stores/chatStore';
import { MessageBubble } from './MessageBubble';
import { InputBox } from './InputBox';

export const ChatContainer: React.FC = () => {
  const { messages, isLoading, sendMessage } = useChatStore();
  const containerRef = useRef<HTMLDivElement>(null);
  
  // 自动滚动到底部
  useEffect(() => {
    if (containerRef.current) {
      containerRef.current.scrollTop = containerRef.current.scrollHeight;
    }
  }, [messages]);
  
  const handleSend = async (content: string) => {
    await sendMessage(content);
  };
  
  return (
    <div className="flex flex-col h-full">
      {/* 消息列表 */}
      <div 
        ref={containerRef}
        className="flex-1 overflow-y-auto p-4 space-y-4"
      >
        {messages.map((msg) => (
          <MessageBubble key={msg.id} message={msg} />
        ))}
        
        {/* 加载状态 */}
        {isLoading && (
          <div className="flex items-center gap-2 text-text-secondary">
            <LoadingSpinner />
            <span>AI 正在思考...</span>
          </div>
        )}
      </div>
      
      {/* 输入框 */}
      <div className="p-4 border-t border-border-color">
        <InputBox onSend={handleSend} disabled={isLoading} />
      </div>
    </div>
  );
};
```

```tsx
// InputBox.tsx
import React, { useState } from 'react';

interface Props {
  onSend: (content: string) => void;
  disabled?: boolean;
}

export const InputBox: React.FC<Props> = ({ onSend, disabled }) => {
  const [input, setInput] = useState('');
  
  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (input.trim() && !disabled) {
      onSend(input.trim());
      setInput('');
    }
  };
  
  return (
    <form onSubmit={handleSubmit} className="flex gap-2">
      {/* 上传按钮 */}
      <button
        type="button"
        className="p-3 rounded-xl bg-bg-secondary hover:bg-bg-tertiary transition"
        title="添加文件"
      >
        <PaperClipIcon className="w-5 h-5" />
      </button>
      
      {/* 输入框 */}
      <input
        type="text"
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="描述你想要创建的应用..."
        disabled={disabled}
        className="
          flex-1 px-4 py-3 rounded-xl
          bg-bg-tertiary border border-border-color
          text-text-primary placeholder-text-muted
          focus:outline-none focus:border-primary
          transition
        "
      />
      
      {/* 发送按钮 */}
      <button
        type="submit"
        disabled={!input.trim() || disabled}
        className="
          px-6 py-3 rounded-xl
          bg-primary hover:bg-primary-hover
          text-white font-medium
          disabled:opacity-50 disabled:cursor-not-allowed
          transition
        "
      >
        <SendIcon className="w-5 h-5" />
      </button>
    </form>
  );
};
```

```typescript
// services/agent/AgentService.ts
import { LLMService } from '../llm/LLMService';
import { CodeGenerator } from './CodeGenerator';
import { CommandExecutor } from './CommandExecutor';
import { SandboxManager } from '../sandbox/SandboxManager';
import { EventEmitter } from 'events';

interface AgentConfig {
  model?: string;
  temperature?: number;
}

export class AgentService extends EventEmitter {
  private llm: LLMService;
  private codeGen: CodeGenerator;
  private executor: CommandExecutor;
  private sandbox: SandboxManager;
  
  constructor(config: AgentConfig = {}) {
    super();
    this.llm = new LLMService(config);
    this.codeGen = new CodeGenerator();
    this.executor = new CommandExecutor();
    this.sandbox = new SandboxManager();
  }
  
  async processRequest(
    userInput: string,
    context: {
      files?: Map<string, string>;
      sandboxId?: string;
    }
  ): Promise<AsyncIterable<string>> {
    // 1. 理解用户意图
    this.emit('status', { message: '正在理解您的需求...' });
    
    const prompt = this.buildPrompt(userInput, context);
    
    // 2. 流式生成响应
    const stream = await this.llm.stream(prompt);
    
    // 3. 解析并执行命令
    return this.parseAndExecute(stream, context);
  }
  
  private buildPrompt(userInput: string, context: any): string {
    const fileList = context.files
      ? Array.from(context.files.keys()).join(', ')
      : '无';
    
    return `
你是 Atoms.dev 的 AI 助手，擅长根据用户需求生成代码。

当前项目文件: ${fileList || '空项目'}

用户需求: ${userInput}

请按照以下步骤执行:
1. 分析需求，确定需要创建/修改的文件
2. 生成代码
3. 如果需要安装依赖或运行命令，输出对应的命令

输出格式:
\`\`\`
分析: [你的分析]
${fileList ? '修改:' : '创建:'}
\`\`\` [文件路径]
\`\`\`[语言]
[代码内容]
\`\`\`

命令:
\`\`\`bash
[命令]
\`\`\`
`;
  }
  
  private async *parseAndExecute(
    stream: AsyncIterable<string>,
    context: any
  ) {
    let buffer = '';
    let sandboxId = context.sandboxId;
    
    for await (const chunk of stream) {
      buffer += chunk;
      yield chunk;
      
      // 检测命令执行时机
      if (buffer.includes('```bash')) {
        const commands = this.extractCommands(buffer);
        for (const cmd of commands) {
          this.emit('command', { command: cmd, sandboxId });
          
          // 执行命令
          const result = await this.executor.execute(cmd, sandboxId);
          this.emit('command_result', { command: cmd, result, sandboxId });
        }
      }
      
      // 检测代码块
      if (buffer.includes('```') && buffer.includes('```')) {
        const files = this.extractCodeBlocks(buffer);
        for (const [path, content] of Object.entries(files)) {
          // 如果没有 sandbox，创建新的
          if (!sandboxId) {
            sandboxId = await this.sandbox.create();
            this.emit('sandbox_created', { sandboxId });
          }
          
          // 写入文件
          await this.sandbox.writeFile(sandboxId, path, content);
          this.emit('file_created', { path, sandboxId });
        }
      }
    }
  }
  
  private extractCodeBlocks(content: string): Record<string, string> {
    const blocks: Record<string, string> = {};
    const regex = /```[\w]*\n([\s\S]*?)```/g;
    let match;
    
    while ((match = regex.exec(content)) !== null) {
      const block = match[1];
      // 尝试从上下文获取文件名
      const pathMatch = content.substring(0, match.index).match(/[\w-]+\.\w+$/);
      if (pathMatch) {
        blocks[pathMatch[0]] = block;
      }
    }
    
    return blocks;
  }
  
  private extractCommands(content: string): string[] {
    const commands: string[] = [];
    const regex = /```bash\n([\s\S]*?)```/g;
    let match;
    
    while ((match = regex.exec(content)) !== null) {
      commands.push(match[1].trim());
    }
    
    return commands;
  }
}

import { Configuration, OpenAIApi } from 'openai';
import Anthropic from '@anthropic-ai/sdk';

interface LLMConfig {
  provider: 'openai' | 'anthropic';
  apiKey: string;
  model?: string;
  temperature?: number;
}

export class LLMService {
  private client: OpenAIApi | Anthropic;
  private provider: 'openai' | 'anthropic';
  private model: string;
  private temperature: number;
  
  constructor(config: LLMConfig) {
    this.provider = config.provider;
    this.model = config.model || 'gpt-4o';
    this.temperature = config.temperature || 0.7;
    
    if (config.provider === 'openai') {
      const configuration = new Configuration({ apiKey: config.apiKey });
      this.client = new OpenAIApi(configuration);
    } else {
      this.client = new Anthropic({ apiKey: config.apiKey });
    }
  }
  
  async stream(prompt: string): Promise<AsyncIterable<string>> {
    if (this.provider === 'anthropic') {
      return this.streamAnthropic(prompt);
    }
    return this.streamOpenAI(prompt);
  }
  
  private async *streamOpenAI(prompt: string): AsyncIterable<string> {
    const client = this.client as OpenAIApi;
    
    const response = await client.createChatCompletion(
      {
        model: this.model,
        messages: [{ role: 'user', content: prompt }],
        stream: true,
        temperature: this.temperature,
      },
      { responseType: 'stream' }
    );
    
    const stream = response.data as any;
    
    for await (const chunk of stream) {
      const content = chunk.choices[0]?.delta?.content;
      if (content) {
        yield content;
      }
    }
  }
  
  private async *streamAnthropic(prompt: string): AsyncIterable<string> {
    const client = this.client as Anthropic;
    
    const stream = await client.messages.stream({
      model: this.model || 'claude-sonnet-4-20250514',
      max_tokens: 4096,
      messages: [{ role: 'user', content: prompt }],
      stream: true,
    });
    
    for await (const event of stream) {
      if (event.type === 'content_block_delta' && event.type === 'text') {
        yield event.text;
      }
    }
  }
}

// websocket/SocketHandler.ts
import { Server as HTTPServer } from 'http';
import { Server, Socket } from 'socket.io';
import { AgentService } from '../services/agent/AgentService';
import { SandboxManager } from '../services/sandbox/SandboxManager';

export class SocketHandler {
  private io: Server;
  private agentService: AgentService;
  private sandboxManager: SandboxManager;
  
  constructor(httpServer: HTTPServer) {
    this.io = new Server(httpServer, {
      cors: {
        origin: '*',
        methods: ['GET', 'POST'],
      },
    });
    
    this.agentService = new AgentService();
    this.sandboxManager = new SandboxManager();
    
    this.setupHandlers();
  }
  
  private setupHandlers(): void {
    this.io.on('connection', (socket: Socket) => {
      console.log('Client connected:', socket.id);
      
      // 处理聊天消息
      socket.on('chat:message', async (data: { content: string }) => {
        try {
          const { content } = data;
          
          // 获取当前项目的 sandbox
          const sandboxId = socket.data.sandboxId;
          
          // 流式处理请求
          const stream = await this.agentService.processRequest(
            content,
            { sandboxId }
          );
          
          for await (const chunk of stream) {
            socket.emit('chat:chunk', { content: chunk });
          }
          
          socket.emit('chat:end', {});
        } catch (error) {
          socket.emit('chat:error', {
            message: error.message,
          });
        }
      });
      
      // Agent 事件
      this.agentService.on('status', (data) => {
        socket.emit('agent:status', data);
      });
      
      this.agentService.on('command', (data) => {
        socket.emit('agent:command', data);
      });
      
      this.agentService.on('command_result', (data) => {
        socket.emit('agent:command_result', data);
      });
      
      this.agentService.on('file_created', (data) => {
        socket.emit('agent:file_created', data);
      });
      
      this.agentService.on('sandbox_created', async (data) => {
        socket.data.sandboxId = data.sandboxId;
        const previewUrl = this.sandboxManager.getPreviewUrl(data.sandboxId);
        socket.emit('sandbox:ready', { previewUrl });
      });
      
      // 断开连接
      socket.on('disconnect', () => {
        console.log('Client disconnected:', socket.id);
        this.cleanup(socket);
      });
    });
  }
  
  private async cleanup(socket: Socket): Promise<void> {
    if (socket.data.sandboxId) {
      // 延迟销毁沙箱，给用户恢复连接的机会
      setTimeout(async () => {
        if (this.io.sockets.sockets.size === 0) {
          await this.sandboxManager.destroy(socket.data.sandboxId);
        }
      }, 5 * 60 * 1000); // 5分钟后销毁
    }

## 八、关键决策与风险

### 8.1 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 为什么用 React？ | 组件化、生态成熟、AI 生成代码友好 | |
| 为什么用 Zustand？ | 轻量、API 简洁、适合中小型状态 | |
| 为什么用 Claude？ | 代码能力强、价格适中 | |
| 为什么用 iframe？ | 简单隔离、支持所有框架、热更新易实现 | |

### 8.2 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| LLM 生成代码质量不稳定 | 高 | 限制生成范围，提供编辑能力 |
| 沙箱资源消耗大 | 中 | 容器池化，延迟销毁，资源限制 |
| 实时预览延迟 | 中 | 增量更新，优化同步策略 |
| 多用户并发 | 高 | 水平扩展，沙箱池管理 |

### 8.3 简化说明

MVP 做了以下简化：

1. **单 Agent**：暂不实现多 Agent 协作
2. **本地生成**：生成代码直接在本地文件系统
3. **简化沙箱**：使用 Docker 容器而非 K8s
4. **无持久化**：重启后项目丢失（后续加数据库）
5. **无权限控制**：所有用户共享部分沙箱池
